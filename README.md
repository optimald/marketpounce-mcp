# MarketPounce MCP

Public connector stub for the hosted MarketPounce MCP server.

Endpoint: https://www.marketpounce.com/api/ops/mcp

Docs: https://www.marketpounce.com/docs/mcp

Privacy: https://www.marketpounce.com/privacy

Auth uses Clerk OAuth 2.1. After login, call list_brands, then set_brand.
